# Статус проекта Com.Post

> Общий актуальный контекст трёх репозиториев и полный перечень последних изменений находятся в [`../CONTEXT.md`](../CONTEXT.md).

Последняя серверная проверка: 8 августа 2026 года — `44 passed`, production Compose валиден, API healthy, `ml-trainer` использует кэшированные TACO-веса. Создание датасета вынесено на `/web/ml/dataset-create`; администратор выбирает ручные загрузки и фотографии с завершённой модерацией. Идентификатор пользователя в manifest не сохраняется.

## Исходные материалы

Проверены три репозитория и 36 релевантных файлов из каталогов ВКР, СИИТ и НиОВС: текст ВКР и ТЗ, SQL-модель, презентации, диаграммы, матрица доступа, практические работы и реестр рисков. Подробный результат — `docs/source-materials.md`.

## Реализовано

- FastAPI + PostgreSQL: JWT, роли USER/MODERATOR/ADMIN/ENGINEER, карта и QR, геопроверка, access sessions, HMAC-команды, подтверждения, S3-фото, модерация, нарушения, блокировки, баллы, телеметрия и аудит.
- Полный локальный Docker-стенд: API, PostgreSQL, MinIO, инициализация bucket и ML service.
- Baseline анализа фото: прозрачная цветовая эвристика с `LIKELY_VALID`, `LIKELY_INVALID`, `NEEDS_MANUAL_REVIEW`; ручная модерация остаётся обязательной.
- Android Compose: вход по роли, Google-карта, QR-сканер CameraX/ML Kit, геолокация, BLE OPEN/CLOSE, фото, рейтинг, кабинет модератора, административная сводка, пользователи/роли/блокировки, компостеры и аудит, инженерная диагностика.
- ESP32/PlatformIO: NimBLE, JSON v1, HMAC-SHA256, срок команды, replay-кэш, notify-ответы, безопасный `MockLockController`, тестовые BLE-клиенты.

## Архитектурные решения

Android не подписывает и не выдаёт разрешения: backend создаёт одноразовую команду, а телефон только передаёт её по BLE. У каждого компостера отдельный секрет. QR идентифицирует точку, но не заменяет вход, серверную геопроверку и подписанную команду. ML изолирован HTTP-контрактом и может быть заменён обученной моделью без изменения мобильного приложения.

## Выполненные проверки

- Backend: `pytest -q` — 7 passed.
- Интеграционный smoke: реальный Docker API → PostgreSQL → MinIO → ML; подтверждены регистрация, профиль, OPEN/CLOSE ack, фото, `LIKELY_VALID`, модерация и история `CLOSED/APPROVED`.
- Docker: четыре долгоживущих сервиса healthy; minio-init завершён успешно; seed создал 4 аккаунта и 2 точки.
- Android: `test assembleDebug` — BUILD SUCCESSFUL из временного ASCII-пути; unit-тесты QR прошли, debug APK создан.
- Android runtime: APK установлен в AVD `Medium_Phone`; подтверждены вход пользователя, карта, профиль, история и вход администратора со сводкой оборудования. Найден и исправлен переход после авторизации, который ранее не наблюдался Compose.
- ESP32: `platformio run` — SUCCESS; RAM 11.1%, Flash 47.9%.
- USB-SERIAL CH340 на COM9 подтверждён как ESP32-D0WD-V3. Безопасная mock-прошивка успешно записана, esptool проверил SHA всех разделов, а после аппаратного перезапуска serial-лог подтвердил `SPI_FAST_FLASH_BOOT` и `BLE_READY`.
- После включения пользовательской BLE-службы Windows плата обнаружена по адресу `78:1C:3C:2C:38:E6` с RSSI −67 dBm. Подписанная OPEN вернула `SUCCESS/OPEN`, CLOSE — `SUCCESS/CLOSED`, а повтор идентичного payload — `REPLAY_DETECTED`; радиоканал, HMAC-контракт, mock-замок и replay-защита подтверждены на реальном ESP32.

## Ограничения прототипа

- Эвристика фото не является обученной моделью и нуждается в датасете/метриках перед автоматическим решением.
- Replay-кэш ESP32 находится в RAM; production требует NVS, secure boot и flash encryption.
- Физический ServoLockController заблокирован до подтверждения платы, схемы, питания и пинов.
- Google Maps требует приватный API key; production требует HTTPS и отключения cleartext traffic.
- Android unit-тесты на Windows не стартуют из пути с кириллицей из-за ограничения Gradle; проверка выполнена на идентичной копии в ASCII-пути.
- Нет подтверждённой аппаратной телеметрии датчиков заполнения/батареи: API и интерфейс готовы, данные пока вводятся тестово.

## Демонстрация ВКР

1. `docker compose up --build`, затем `docker compose exec api python -m app.seed`.
2. Войти `user@example.com / User123!`, выбрать точку на карте или QR.
3. После разрешённой прошивки ESP32 выполнить OPEN, фото и CLOSE.
4. Войти `moderator@example.com / Moderator123!`, проверить фото и отклонить/принять.
5. Войти `admin@example.com / Admin123!`, показать аналитику, роли, блокировки, компостеры и аудит.
6. Показать результат baseline ML, начисление баллов и блокировку после третьего нарушения.
