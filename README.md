# Community Compost backend

Архитектурные границы и правила модулей: [docs/architecture.md](docs/architecture.md).
Результаты проверки сервера и решение по микросервисам: [docs/server-review.md](docs/server-review.md).

Основной API проверен с Python 3.12 и 3.14; полный набор зависимостей для разработки и ML зафиксирован для Python 3.12. Для воспроизводимого запуска тестов используйте Python 3.12 и `pip install -r requirements-dev.txt`, затем `pytest -q`. Проверка PostgreSQL принимает `TEST_DATABASE_URL` (только для тестовой базы); CI прогоняет оба варианта.

FastAPI-сервер выпускного проекта: авторизация, карта/QR, одноразовые BLE-команды, фото, baseline-классификатор, модерация, полноценный административный API, телеметрия, аудит, баллы, нарушения и блокировка после трёх нарушений.

Регистрация проверяет email, имя и сложность пароля. JWT содержит `iat`/`exp`; API различает просроченный и повреждённый токен. Обычный перезапуск API не сбрасывает сессии, если `JWT_SECRET` и PostgreSQL сохранены.

Связанные компоненты: [Android-приложение](https://github.com/SirFerr/com-post-android-app) · [прошивка ESP32](https://github.com/SirFerr/com-post-iot).

## Локальный запуск

```bash
docker compose up --build
docker compose exec api python -m app.seed
```

API: `http://localhost:8000`, веб-панель персонала: `/web`, Swagger: `/docs`, MinIO console: `http://localhost:9001`.

Веб-панель разделяет возможности по ролям: модерация фотографий, оборудование и телеметрия для инженера, пользователи/роли/блокировки и аудит для администратора. При добавлении базовой ESP32 сервер сам создаёт секрет, Android передаёт его устройству по BLE, а интерфейс никогда его не показывает.

Перед seed задайте `BOOTSTRAP_ADMIN_EMAIL` и `BOOTSTRAP_ADMIN_PASSWORD` (не короче 12 символов). Встроенного пароля нет. Пользователи регистрируются самостоятельно, а роли модератора и инженера назначает администратор. Роль администратора выдаётся только через веб-панель.

Регистрация требует пароль от 8 символов с заглавной и строчной буквами и цифрой; специальный символ не требуется. Изменение пользователей и оборудования требует повторного ввода пароля действующего администратора.

Веб-интерфейс сотрудников открывается по адресу `http://localhost:8000/web` на серверном компьютере или `http://192.168.1.212:8000/web` из локальной сети. Корневой адрес `:8000/` перенаправляет в веб-панель.

Без Docker: `python -m venv .venv`, установить `requirements.txt`, затем `python -m app.seed` и `uvicorn app.main:app --reload`. Тесты: `pytest -q`.

Переменные: `DATABASE_URL`, `JWT_SECRET`, `JWT_TTL_MINUTES`, `WEB_SESSION_TTL_DAYS`, `COMMAND_TTL_SECONDS`, `S3_ENDPOINT`, `S3_PUBLIC_ENDPOINT`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_BUCKET`, `ML_SERVICE_URL`. Веб-авторизация хранится в защищённой `HttpOnly` cookie в течение 30 дней по умолчанию; срок настраивается через `WEB_SESSION_TTL_DAYS`.

ML-контейнер загружает фото из MinIO и применяет прозрачную эвристику цветовых областей (`LIKELY_VALID`, `LIKELY_INVALID`, `NEEDS_MANUAL_REVIEW`). Решение не заменяет модератора и подготовлено так, чтобы позже заменить реализацию `/analyze` обученной моделью без изменений Android и бизнес-процесса.

Операционный контур обучения, предобучение на TACO, версионирование датасета, запуск из веб-панели и правила итерации описаны в [`docs/ml-operations.md`](docs/ml-operations.md). Пользовательские фотографии не используются: к TACO добавляются только материалы, отдельно загруженные администратором в ML-раздел. До ручной публикации кандидата сервис продолжает использовать `color-heuristic-v1`.

Готовая конфигурация для развёртывания на Linux-сервере с HTTPS, PostgreSQL, двумя S3-хранилищами, ML-сервисом, постоянным обработчиком обучения и резервным копированием описана в [`docs/deployment.md`](docs/deployment.md).

Архитектура и ограничения описаны в каталоге `docs`. Для демонстрации: запустить Compose, выполнить seed, войти пользователем, выбрать ближайший компостер, пройти OPEN, загрузить фото, выполнить CLOSE, затем отклонить проверку модератором.
